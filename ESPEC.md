## Pedidos del usuario (textuales, en orden)
1. Sistema de recomendación de películas distribuido sobre MovieLens 25M (https://grouplens.org/datasets/movielens/25m/), para presentar en una expo con póster. RESTRICCIÓN OBLIGATORIA: PySpark (Spark MLlib) para el procesamiento y entrenamiento distribuido, y Apache Kafka para la ingesta de calificaciones en streaming. Dask opcional, solo si aporta una comparación. Componentes: 1. Ingesta: script que descarga ml-25m y un productor Kafka que reproduce ratings.csv en orden de timestamp a velocidad configurable (simula usuarios calificando en vivo), topic "ratings". 2. Recomendador batch en Spark: ALS de MLlib con partición temporal (entrenar antes de una fecha, evaluar después), RMSE, Precision@10 y NDCG@10 contra una línea base de popularidad. 3. Perfil de gustos por usuario: géneros y tag genome ponderados por sus calificaciones; agrupar usuarios con KMeans en "tipos de espectador" con nombres interpretables. 4. Streaming: Spark Structured Streaming lee de Kafka y actualiza en tiempo real los perfiles y las recomendaciones de los usuarios activos; el reentrenamiento de ALS es periódico por lotes. 5. Experimento de escalabilidad: tiempos y speedup con 1, 2, 4 y 6 núcleos, en gráfico para el póster. 6. Interfaz web en Streamlit con chat LLM: el usuario ingresa su userId; el LLM usa herramientas (sin inventar datos) para ver sus películas, calificaciones, tags y perfil de gustos, combina eso con lo que pide en el chat (ej. "algo corto y liviano para hoy") y explica por qué recomienda cada película. LLM por defecto: Ollama local con qwen3.5:9b, configurable. 7. Enriquecimiento opcional y legal: IMDb non-commercial datasets unidos por links.csv; pósters y sinopsis desde la API de TMDb con la clave en la variable de entorno TMDB_API_KEY; importador del CSV de exportación de Letterboxd para un usuario nuevo. Nada de scraping. 8. Material para el póster: diagrama de arquitectura, figuras de métricas, speedup y tipos de espectador, y un README con guía de la demo en vivo. Entorno: Windows 11, Ryzen 5 3600 (6 núcleos), 16 GB RAM, RTX 5060 8 GB. Kafka ya corre en Docker en localhost:9092 (lo levanto yo; no ejecutes docker). Java 17 y Python 3.12 instalados por mí: crea un entorno virtual con py -3.12. Entrega check_entorno.py que verifique Java, HADOOP_HOME/winutils y Kafka, y me diga qué falta.
